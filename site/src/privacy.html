Privacy Policy

Last updated: September 17, 2026

This policy explains how camdjackson.com and any personal tools operated by Cameron Jackson (the "Owner") handle data.

The website

This is a static website. It does not require accounts, does not run third-party advertising or tracking, and does not collect personal information from visitors beyond standard server request logs kept by the hosting provider.

Personal tools and third-party platforms

The Owner operates personal tools that connect to third-party platforms (for example TikTok, YouTube, and Google Drive) using the Owner's own authorized credentials. These tools:

  • access only the Owner's own accounts and the Owner's own content;
  • are used to manage the Owner's own videos, for example uploading the Owner's own videos to the Owner's own drafts for review and posting;
  • do not collect, store, or share any other person's personal data;
  • store authorization tokens only locally on the Owner's own machine, never transmitted to any third party other than the platform they authenticate with.

Data sharing

No visitor or user data is sold or shared. Data exchanged with a third-party platform is limited to what that platform requires to perform an action the Owner explicitly initiated on the Owner's own account.

Changes

This policy may be updated from time to time; the current version is always posted here.
